# FastSend（快速互传）

FastSend 是一款开源的 Android 文件互传应用，目标是让附近设备之间传输文件变得简单、快捷。

> **项目状态：开发中。** 功能和设备兼容性可能因设备型号、Android 版本及系统权限而有所不同。

## 项目目标

- 让附近设备之间的文件传输更加简单。
- 探索多种设备发现与连接方式，提升不同设备之间的兼容性。
- 保持项目开源，方便用户通过应用商店以外的渠道获取。

## 传输方式

项目正在开发多种传输与设备发现方式，包括 Google Nearby、蓝牙低功耗（BLE）、NFC 辅助连接和局域网传输。

具体功能是否可用，取决于当前实现、设备硬件、Android 版本以及用户授予的权限。

## 从源码构建

1. 安装兼容版本的 Android Studio 和所需的 Android SDK。
2. 克隆本仓库：

   ```bash
   git clone https://github.com/SteveYuanlong9321/FastSend.git
   ```

3. 使用 Android Studio 打开项目根目录，并等待 Gradle 同步完成。
4. 构建应用，并在自己的设备上进行测试。

项目仍在开发中，具体构建要求可能会随版本变化。完整项目源码将在整理完成后上传至本仓库。
