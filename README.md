# FastSend

**FastSend** is an open-source Android app focused on fast, local device-to-device file transfer.

> Project status: under active development. Features and compatibility may vary by device.

## Goals

- Make sending files between nearby devices straightforward.
- Explore multiple connection methods for practical device compatibility.
- Keep the project open source and easy to obtain outside app stores.

## Current transfer methods

The project is being developed with support for several transfer and discovery paths, including Google Nearby, Bluetooth Low Energy (BLE), NFC-assisted connection, and local-network transfer. Availability depends on the implementation, Android version, device hardware, and permissions.

## Build

1. Install a compatible version of Android Studio with the Android SDK.
2. Clone this repository:
   ```bash
   git clone https://github.com/SteveYuanlong9321/FastSend.git
   ```
3. Open the project root in Android Studio and allow Gradle sync to finish.
4. Build and test the app on your device.

Build requirements may change while the project is under development. The project source will be added to this repository as it is prepared for publication.
